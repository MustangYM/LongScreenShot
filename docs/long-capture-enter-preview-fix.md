# 长截图回车完成与预览横线

长截图会主动把焦点交还浏览器，仅处理截图浮层 keyDown 无法收到回车。现在仅在长截图会话期间注册无修饰键的 Return 和小键盘 Enter，转到已有完成并复制流程，不受普通截图快速复制设置影响。浮层拥有焦点时也处理相同操作。已有 finishing 状态阻止重复提交；成功、取消和关闭释放注册。提示文字同步更新。

预览段的起点及高度原先分别四舍五入，会出现 round(start)+round(height) 与 round(end) 相差一行的情况，透明空行露出后面的黑色背景。现在按共享文档边界计算每段预览高度，预缩放帧路径也匹配该高度。修改仅影响预览，成品图的像素和拼接位置不变。

47 项 Debug 测试通过。新增主键盘/小键盘确认键及修饰键检查，以及非整数比例下 455 次小段追加、跨 tile、普通和预缩放两种路径的逐行 alpha 检查。真实浏览器焦点下的按回车复制及预览画面仍待实机确认。
