# 宽选区长截图性能修正

在本机 Debug 构建用 4400×2400、120 帧的完整管线回放复现性能不足。测试包含像素复制、签名、匹配、画布追加、预览，以及启动不匹配、静止和连续滚动。修改前平均 38.98ms/帧，超过 60fps 的 16.67ms 预算；模拟积压远超 192MiB 队列限额。这证明宽选区存在可复现的性能瓶颈，但尚未拿到用户此次中断的运行日志，不能断言所有“断掉”都由积压引起。

修正：
- 先生成最多 144 列的匹配图，再转换亮度，保持所有源图行；同格式 RGB 图避免全尺寸格式转换。原始采集及导出分辨率不变。
- 将行按相位分组，每个候选位移使用有界行样本计算 NCC。仍穷举每一个整数位移，不量化纵向位置，不跳过采集帧。
- 使用 Accelerate 计算纵向梯度，对最终候选的每一重叠行及独立横向列复核；仍拒绝重复纹理歧义。

修改后同测试平均 14.21ms/帧，模拟峰值队列约 40.3MiB。原 1948×1458 测试平均 6.41ms/帧。模拟队列包含复制耗时，是测试估算，不代表实机采集队列日志。

41 项 Debug 测试通过。新增全宽 Retina 性能测试、各采样相位下 1px 位移和反向滚动、较高视口重复内容拒绝、BGRA/ARGB/ABGR 图像签名一致性测试。性能结果受设备负载影响；尚未实机重演用户的宽内容页面。
